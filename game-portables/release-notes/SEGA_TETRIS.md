# DreamcastRecompiled — Sega Tetris Direct Portable V1.2 (Tester)

**Windows x64 — lightweight precompiled DreamcastRecompiled portable.**

This archive includes the title-specific SH-4 native game module, Windows host runtime, GD-ROM/Maple/network plugins, and incremental native patches. No separate compilation or Python installation is needed to test the packaged game path.

## Test status

- The maintainer reached Sega Tetris gameplay with functioning audio and graphics using a community-patched Japanese build.
- An intermittent crash has been observed.
- This is an **experimental tester**, not a guarantee of crash-free gameplay or support for every game revision.

## How to try

1. Extract the complete ZIP.
2. Run `DreamcastRecompiled.exe` on Windows x64.
3. Select your own compatible Sega Tetris CDI/GDI.
4. Report your hardware, game revision, performance, screenshots and logs.

**No game disc image or Sega firmware is included.** This independent project is unaffiliated with Sega; commercial game-derived material remains subject to third-party rights.
