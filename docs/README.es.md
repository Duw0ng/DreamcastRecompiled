# DreamcastRecompiled v1.2 — Language Support

[Main documentation (English)](../README.md) · [Releases](https://github.com/Duw0ng/DreamcastRecompiled/releases) · [ChuChu Rocket! tester guide](CHUCHU_ROCKET_TESTER_V1.2.md)

This page previously contained a Spanish-language copy of the v1.2 release guide. The public GitHub documentation is now maintained in **English** to avoid conflicting or out-of-date instructions.

The bundled Aqua application continues to support **both English and Spanish interface languages**. This documentation change does not remove Spanish localization from the actual application.

For installation, native SH-4 recompilation details, controller and VMU setup, supported game versions, known limitations, and legal notices, consult the [up-to-date English README](../README.md) and the [game-portable catalog](../game-portables/README.md).

Direct game portables have moved to **v1.2 Rev 2**. They preserve the original launcher and implement the raw CDI plain/scrambled boot correction; the SGGG update also fixes a confirmed recurring menu sound effect.
