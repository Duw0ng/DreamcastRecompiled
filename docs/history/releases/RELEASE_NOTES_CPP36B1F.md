- Modern controller setup enlarged and upgraded with a live graphical Dreamcast pad.
- Preview shows mapped Dreamcast input rather than raw host button numbers.
- D-pad and A/B/X/Y/START illuminate in real time.
- Analog stick knob moves in real time.

- Refresh devices, per-port device selection, expansion slots and XInput rumble test remain available.

- Runtime build ID intentionally unchanged from cpp36b1e; no Runtime/plugin rebuild is required just for this release.
