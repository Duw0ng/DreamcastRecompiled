USO EN WINDOWS
--------------
1. Tener Visual Studio/C++ y CMake disponibles.
2. Ejecutar build_windows.bat si se quiere compilar herramientas primero.
3. Para una prueba comercial unificada:
       run_universal_0.0.209.bat "C:\ruta\al\juego.cdi"

Los juegos NO vienen incluidos en este ZIP.
