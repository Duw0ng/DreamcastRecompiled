# DreamcastRecomp 0.0.28 — validation record

## Main project

Configured and built on Linux with GCC 14.2.0:

```text
cmake -S DreamcastRecomp_0.0.28 -B build_0028 -DCMAKE_BUILD_TYPE=Release
cmake --build build_0028 -j4
ctest --test-dir build_0028 --output-on-failure -j4
```

Result:

```text
100% tests passed, 0 tests failed out of 47
```

The new `arm7_tests` coverage includes:

- FIQ line entry;
- FIQ bank/vector and masks;
- `SUBS pc,lr,#4` return with CPSR restoration;
- reset IRQ masking;
- IRQ unmask and vector entry.

`cpp_emitter_tests` additionally verifies that the emitted runtime contains timer/interrupt routing, the new runner switches and the exception-enabled standalone ARM7 source.

## Standalone single-function generated project

The project generated by `cpp_emitter_tests` was independently configured and compiled. Its generated sources include:

```text
dc_runtime.cpp
dc_arm7.cpp
dc_image.cpp
dc_native_overrides.cpp
generated_main.cpp
generated_compile_test.cpp
```

`generated_compile_test` executed successfully.

Its AICA smoke is no longer the 0.0.27 `MOV r0,#42` loop. It now executes a miniature firmware and verifies Timer A -> FIQ -> code 2 -> SCIRE -> exception return.

## Standalone multi-function generated project

A representative `emit_cpp_program` output (`dc_recomp_multifunc_output`) was also configured and compiled independently. Its `generated_compile_test` executed successfully with the same Timer A/FIQ regression.

This is important because DreamcastRecomp has two emitter paths: single-function research output and whole-program output. 0.0.28 verifies that both carry the same native ARM7/AICA behavior.

## PVR regression status

The 0.0.27 TA -> render -> VBlank/page-flip lifecycle remains covered by `cpp_emitter_tests`. No PVR behavior was intentionally removed in 0.0.28.

The previous real 2ndMix packet-limited PVR result remains useful as a graphics regression target, but the actual 2ndMix executable is not present in this source package and therefore was not rerun during this build.

## What this validation proves

It proves that the 0.0.28 sources:

- compile as DreamcastRecomp itself;
- pass all current regressions;
- emit autonomous native projects;
- compile those generated projects;
- execute ARM7 exception logic from generated code;
- raise Timer A through AICA interrupt state;
- deliver a FIQ and return to interrupted ARM firmware.

It does **not** prove that native AICA audio is complete or that 2ndMix music already plays.
